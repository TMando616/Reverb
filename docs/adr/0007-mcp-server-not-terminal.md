# ADR-0007: ブラウザ内ターミナルではなく MCP サーバーで Claude Code と連携する

- **日付**: 2026-08-26
- **ステータス**: 採用

## 背景

ネタ出しは Obsidian の断片メモを読みながら行う。これを Claude Code に任せ、結果をサービスに流し込みたい。

ただし**動かせない制約が1つある。**

> **Obsidian Vault はローカル（WSL 経由の OneDrive）にあり、AWS 上のサービスからは物理的に到達できない。**

つまり「サービスが Vault を読む」構成は成立しない。Vault を読めるのはローカルで動くプロセスだけである。

## 選択肢

| # | 方式 | 中身 |
|---|---|---|
| 1 | **ブラウザ内ターミナル** | xterm.js + node-pty で PTY を WebSocket 配信し、コンテナ内で Claude Code CLI を起動する |
| 2 | **Claude Agent SDK をサーバーに組み込む** | Claude Code をライブラリ化したもの（`@anthropic-ai/claude-agent-sdk`）を自前サーバーで動かし、ブラウザにはチャットUIを出す |
| 3 | **サービスを MCP サーバーとして公開する** | ローカルの Claude Code から、サービスの API をツールとして叩く |

## 決定

**3 を採用する。サービス側に MCP サーバーを実装し、手元の Claude Code から操作する。**

```
ローカル（WSL）                        AWS
┌──────────────────┐              ┌────────────────────┐
│  Claude Code     │              │  NestJS API        │
│   ↕ Obsidian     │◄────MCP─────►│   + MCPサーバー     │
│  （断片メモを読む）│  (トークン認証) │                    │
└──────────────────┘              └────────────────────┘
```

公開するツール：`list_ideas` / `create_content` / `update_content` / `search_published` / `get_metrics` / `publish`

## 理由

### 1. 物理的制約をそのまま解ける

**Vault を読むのはローカルの Claude Code の役割**とし、結果だけを MCP 経由でサービスに書き込む。
サービス側から Vault へは一切アクセスしない（一方向）。

### 2. ターミナルは出力が構造化データにならない ★決定的

ターミナルに流れるのは文字列である。**「いまネタが3件生まれた」をサービスが認識できない。**

本サービスの価値は構造化された記録（状態遷移・指標の時系列）にあるため、ターミナルとは根本的に相性が悪い。
結局 MCP か API の橋が必要になり、**ターミナルを足す意味がなくなる。**

### 3. Web 経由でシェルを開けることになる

公開デプロイするアプリケーションに、**任意コード実行の面を自分で作ることになる。**
認証を破られた場合の被害が、通常の Web アプリとは比較にならない。

### 4. PTY 配信とコンテナ管理は目的から外れる

PTY のストリーミングとコンテナのライフサイクル管理はインフラ寄りの作業であり、
このプロジェクトで扱いたいバックエンドの設計（レイヤー構成・認可・非同期・データ設計）にはほとんど寄与しない。

### Claude Agent SDK（案2）を Phase 2 に送る理由

ブラウザ上でエージェントと対話できる UX には価値がある。ただし 4ヶ月のスコープには収まらない。
**まず MCP でデータの流れを作るのが先**で、対話UIはその上に載せられる。

> Claude Agent SDK は Claude API とは別プロダクト。ドキュメントは `code.claude.com/docs/en/agent-sdk`。

## 影響

- **MCP サーバーの認証設計が必要になる。** インターネット越しに公開する以上、トークン認証は必須
- **認可は Service 層を経由して画面と共通にする。** MCP 専用の抜け道を作らない（ADR-0009）
- MCP 経由で作られたコンテンツは、作成元が識別できるようにする
- **Claude Code はローカルで動く前提。** デモ閲覧者は MCP を使えず、画面からのみ触れる
- MCP サーバーの実装は既存 Service の薄いラッパーになるため、見積りは 15h に収まる
